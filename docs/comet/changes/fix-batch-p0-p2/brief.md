# Outcome

v0.4.0：14+1 项功能修复与增强——文档预览、会话历史、多类型计算器、法条/案例检索、天眼查企业查询、阶段子项勾选、标准 Word 模板、智能咨询文件上传、UI 磨光，走完整 comet 流程。

# Scope

## P0 功能缺陷
- A1 文档预览：合同审查上传后可查看文本内容（提取+渲染+分页）
- A2 咨询历史：会话 JSONL 持久化+侧栏历史列表+新会话/切换
- A3 咨询上传：输入框旁上传按钮，上传后 agent 工具可引用
- A4 版本号：设置页显示当前版本（读 package.json）
- A5 阶段子项：8 阶段每阶段展开子检查单（打勾+一键生成待办）

## P1 功能增强
- A6 法条检索：内置常用法条库（劳动合同法/民法典/刑法节选）+搜索
- A7 案例检索：本地案例 tab（用户保存的案例）+预留公开数据源接口
- A8 通用计算器：劳动仲裁/交通事故/工伤/借贷利息 tab 切换
- A9 标准 Word 模板：python-docx 按律师文书规范排版（页眉/字号/行距/落款）
- A10 天眼查企业查询：后端调天眼查接口+前端查询页（查企业工商信息）
- A11 知识库联动：咨询中 AI 识别法条→提示存入知识库
- A12 案件联动：审查/文书/阅卷结果页加"关联到案件"按钮

## P2 体验优化
- A13 对齐审计：统一行高/图标基线/按钮间距
- A14 界面密度：调优间距/字号/卡片

# Non-goals

- 不做 2B 企业管理面板
- 不接入公开裁判文书网（预留接口，后续版本）
- 不做多主题

# Acceptance examples

- A1: 上传 txt/md/pdf 后，文档行点击展开预览面板显示文本内容
- A2: 发送咨询后关闭重开 app，历史对话在侧栏可见且可切换
- A3: 咨询输入框旁有上传按钮，上传后 agent 对话可引用文件名
- A4: 设置页显示 "版本 0.4.0"
- A5: 案件详情 8 阶段，点开"证据收集"阶段可见子项列表，可逐项打勾，点"生成待办"自动创建
- A6: 法律检索页切换到"法条"tab，搜索"劳动合同"返回法条卡片
- A7: 法律检索页切换到"案例"tab，可查看本地保存的案例
- A8: 计算器页有 tab 切换（劳动/交通/工伤/借贷），切换后表单和结果联动
- A9: 导出 Word 后打开文件，页眉有"法律工作台"、正文排版符合规范
- A10: 侧栏"办案"组新增"企业查询"，输入公司名返回工商信息卡
- A11: 咨询中 AI 回复含法条引用时，末尾出现"存入知识库"按钮
- A12: 合同审查结果页有"关联到案件"下拉，选择后案件详情可见关联文书
- A13: 全局截图视觉审：无错位/对齐问题
- A14: 全局截图视觉审：间距/密度合理
- A15: 全部页面无 console error

# Constraints and invariants

- 浅色主题（禁深色/渐变/发光）
- 渲染层零网络（天眼查走 sidecar 后端）
- 天眼查仅限偶尔查询（禁批量，脚本注释红线）

# Decisions

- D1 天眼查接口封装在 sidecar 的 /api/company/query，前端走 IPC
- D2 法条库硬编码在 backend/app/data/laws.json（约 50 条常用法条）
- D3 会话历史存 ~/.legal-workbench/sessions/*.jsonl
- D4 Word 模板用 python-docx（已在依赖中）
