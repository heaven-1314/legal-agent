工资拖欠与经济补偿主张

会话 #A-2026-0818-06 · 关联工具：法律检索、赔偿计算器、知识库
周

律师您好，公司拖欠我三个月工资了。如果我以这个理由主动离职，还能拿到经济补偿吗？我月工资 8500 元，已经工作了 3 年 2 个月。

律

结论：可以。拖欠工资属于「被迫解除」情形，您仍有权主张经济补偿。

赔偿计算器 经济补偿金测算 · N = 3.5 个月 1.2s ✓
知识库 本地案例库 · 命中同类裁判 12 篇 0.6s ✓

一、依据

  • 《劳动合同法》第 38 条：用人单位未及时足额支付劳动报酬的，劳动者可以解除劳动合同；
  • 第 46 条：依第 38 条解除的，用人单位应当支付经济补偿；
  • 第 47 条：经济补偿按工作年限计算，每满一年支付一个月工资；六个月以上不满一年的，按一年计算。

二、测算（工作 3 年 2 个月 → 按 3.5 个月计）

经济补偿 = 8,500 × 3.5 = 29,750 元
另可主张：拖欠工资 8,500 × 3 = 25,500 元

三、行动建议

  • 先以 EMS 书面催告工资支付，保留凭证；
  • 以第 38 条为由发出《被迫解除劳动合同通知书》，切勿写「个人原因离职」；
  • 自劳动关系终止之日起 1 年内申请劳动仲裁，主张拖欠工资与经济补偿。
